Level 3 of 5 · Managed Autonomy

Managed Autonomy · ORBIT: Bounded

First true delegation, inside human-approved boundaries

Agents execute defined work end to end inside explicit boundaries. Humans approve at checkpoints instead of reviewing line by line. A verification harness carries the load that human attention used to.

Entry gate
First ticket completed AI-driven end to end, with human approval only at defined checkpoints.The insight: Verification shifts from reading code to checking evidence.

Requirements

People & Skills

  • Engineers operate as orchestrators and reviewers of agent output
  • Checkpoint review is a trained skill with defined evidence standards
  • Escalation paths exist for when an agent exceeds its boundary

Process & Workflow

  • Agent-eligible tickets carry a machine-readable definition of done
  • Ticket states distinguish queued-for-agent, in-agent, and checkpoint review
  • Human-in-the-loop checkpoints are defined per workflow, not improvised

Platform & Tooling

  • A verification harness (tests, static analysis, policy checks) gates every merge
  • Agents run in sandboxed environments with scoped credentials
  • Every agent action is captured in an auditable trail

Governance & Risk

  • Boundaries define what agents may read, write, and never touch
  • An approval matrix maps checkpoint types to accountable humans
  • Rollback procedures exist and have been exercised

Measurement

  • Checkpoint pass rates are tracked per workflow
  • Intervention and rework rates distinguish healthy delegation from theater
  • Cycle time is compared for agent-run vs human-run tickets
