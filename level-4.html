Level 4 of 5 · Quantitatively Managed

Quantitatively Managed · ORBIT: Instrumented

Measurement runs the portfolio

Telemetry is on by default. Every named workflow has a baseline and a net ROI figure. Workflows are promoted and retired on data rather than enthusiasm, and spend is governed like any other production system.

Entry gate
Telemetry is on by default with baselines, and at least one workflow has been retired because the numbers said so.The insight: You can only scale what you can kill.

Requirements

People & Skills

  • Capacity planning uses telemetry, not intuition
  • Incentives reward outcomes, never raw usage volume
  • Teams read their own dashboards without an analyst in the loop

Process & Workflow

  • A portfolio review promotes or retires workflows on defined thresholds
  • No workflow rolls out without a baseline captured first
  • Experiment results feed the golden path on a set cadence

Platform & Tooling

  • Telemetry is on by default across every project and tool
  • A collector pattern routes signals to the destination each environment requires
  • Every named workflow has a live dashboard: baseline vs current

Governance & Risk

  • Spend limits are enforced programmatically
  • Model versions are pinned; upgrades pass evaluation before rollout
  • Anti-metrics (lines generated, prompts sent) are explicitly banned from goals

Measurement

  • Net ROI is computed per named workflow, cost included
  • Adoption is read as a funnel, never as an average
  • AI metrics are correlated against the DORA four keys for ground truth

Exit gate
The SDLC is redesigned assuming agents, and AI-native economics appear in pricing or SoWs.The insight: The process is built for agents; humans work by exception.
